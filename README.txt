SHOESTYLE APP — QUICK START

Files:
- index.html : page structure
- style.css  : visual design and responsive layout
- script.js  : product data, gender/category filters, search, and demo bag

HOW TO OPEN
1. Extract the ZIP file.
2. Open index.html in a web browser.
3. Choose Men or Women, select a category, or search for a shoe.
4. Click Add to bag to test the demo shopping bag.

EMPTY FOLDERS
- images/men/       Add men's shoe images here.
- images/women/     Add women's shoe images here.
- images/shared/    Add shared banners or general shoe images here.
- assets/icons/     Add icons or other local assets here.

The folders contain .gitkeep placeholder files so they remain in the ZIP.
To use real product photos, add the image files to the appropriate folder and update
the product data and product-card rendering in script.js.

NOTES
- This is a front-end demo; it does not process real orders or payments.
- Product names and prices are sample data in Nigerian naira (NGN).
- The shoe illustrations are emoji placeholders; no product photos are included.
- Google Fonts is optional. The design falls back to system fonts if offline.
